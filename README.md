# PalaceGrid

A modern desktop client for The Palace on Windows and macOS.

**[Download PalaceGrid and explore the current features](https://glennox2009.github.io/palacegrid-releases/)**

The website resolves the latest published GitHub release automatically and links directly to the correct installer.

## Current highlights

- Multiple Palace connections, bookmarks, history and a live server directory.
- Classic and modern props, a categorized prop bag, loose props and animated-avatar import.
- Doors, room pictures, video backgrounds, embedded media, chat and painting.
- Iptscrae room scripts, a personal `cyborg.ipt`, HTTP callbacks and a script debugger.
- Visual door/spot authoring and operator tools.

## Installers

| Platform | File |
| --- | --- |
| Windows 10/11, 64-bit | `PalaceGrid_x.y.z_x64-setup.exe` |
| macOS, Apple Silicon and Intel | `PalaceGrid_x.y.z_universal.dmg` |

Installers are currently unsigned. Windows may show SmartScreen; choose **More info → Run anyway**. On macOS, use **System Settings → Privacy & Security → Open Anyway**, or run:

```sh
xattr -cr /Applications/PalaceGrid.app
```

See [all releases and release notes](https://github.com/glennox2009/palacegrid-releases/releases).
